## Multimodal Spectroscopic Dataset for Chemistry
All information can be obtained here: https://rxn4chemistry.github.io/multimodal-spectroscopic-dataset/

PS: The dataset is rather large, to inspect the data, in the repository (https://github.com/rxn4chemistry/multimodal-spectroscopic-dataset/tree/main/data/example_data) a demo dataset can be found. The data is compressed as parquet-file, which can be directly read using pandas.
